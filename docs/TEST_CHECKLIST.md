## 🟧 D. 이장님 — 확정 / 취소 / 합치기

> 위 C 시나리오 끝난 상태에서 진행 (대기 5건 정도 쌓여있음)

### D1. 단건 확정
1. 이장님(테스트) 로그인 → 홈에서 **대기 신청 N건** 보임
2. 대기 탭 → 카드 하나의 **✓ 확정** 클릭
3. 모달 "확정하시겠습니까?" → **확정 알림 발송**

| 확인 사항 | OK |
|---|----|
| 모달이 뜨고 버튼이 동작함 (이전 버그 회귀) | ☐ |
| 토스트 "💬 ○○ 님께 확정 알림 발송" | ☐ |
| 그 카드가 **확정 탭**으로 이동 | ☐ |
| 홈의 "대기 신청" 숫자 -1, "오늘 확정" +1 (오늘 날짜인 경우) | ☐ |
| 마을 현황 "오늘 운행" +1 (오늘 날짜이고 합승이 아닌 새 런인 경우) | ☐ |

### D2. 단건 취소 (확정 후)
1. 확정 탭에서 **취소** 클릭 → 사유 입력 (예: 차량 사정)
2. 모달 → **취소 알림 발송**

| 확인 사항 | OK |
|---|----|
| 토스트 발송 | ☐ |
| **취소 탭**으로 이동 | ☐ |

### D3. 대기 단건 취소 (이장님이 거절)
| 확인 사항 | OK |
|---|----|
| 대기 → 취소 클릭 시 사유 prompt | ☐ |
| 취소 탭으로 이동 | ☐ |

### D4. 합치기 (편집 모드)
> 같은 날짜·같은 방향·1시간 이내 대기 2건 이상 있어야 가능

1. 대기 탭 → **편집** 클릭 → 카드들에 체크 동그라미 등장
2. 2건 이상 체크 → 상단 **합치기** 활성화
3. 합치기 클릭 → 다이얼 모달 (시:분 10분 단위)
4. **10:30** 으로 설정 → **✓ 합치기**

| 확인 사항 | OK |
|---|----|
| 다이얼이 10분 단위 (00, 10, 20, 30, 40, 50)만 선택 가능 | ☐ |
| 합치기 성공 토스트 | ☐ |
| 확정 탭에 **"오전 10시 30분"** 으로 표시 (← 분까지 나와야 함) | ☐ |

### D5. 합치기 거부 케이스
1. 다른 날짜 2건 선택 → 합치기 → **MERGE_DATE_MISMATCH**
2. 다른 방향(청산↔옥천 섞임) 2건 → **MERGE_CATEGORY_MISMATCH**
3. 인원 합계 5명 이상 → **MERGE_OVER_CAPACITY**
4. 1시간 초과 떨어진 슬롯들 → **MERGE_HOUR_RANGE**

| 케이스 | 에러 코드 토스트 | OK |
|---|---|----|
| 다른 날짜 | MERGE_DATE_MISMATCH | ☐ |
| 다른 방향 | MERGE_CATEGORY_MISMATCH | ☐ |
| 합계 5명+ | MERGE_OVER_CAPACITY | ☐ |
| 1시간 초과 | MERGE_HOUR_RANGE | ☐ |
